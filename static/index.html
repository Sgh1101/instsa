인스타그램 로그인 설정확인 중

로그인 없이 쓰면 인스타그램이 몇 번 이용한 뒤 요청을 막아요. 쿠키를 등록하면 막힘이 줄고, 내가 팔로우 중인 비공개 계정 게시물도 받을 수 있어요.

  1. PC 브라우저에서 인스타그램에 로그인
  2. F12 → Application(애플리케이션) → Cookies → instagram.com
  3. sessionid의 값(Value)을 복사해 아래에 붙여넣기 (폰으로는 "나에게 보내기"로 전달)

아래 버튼을 누르면 인스타그램 로그인 화면이 열려요. 로그인하면 자동으로 이 앱에 저장됩니다. 비밀번호는 인스타그램이 직접 받고, 이 앱은 로그인 쿠키만 가져와요.

쿠키는 내 계정의 로그인 권한과 같아요. 부계정을 쓰고 다른 사람에게 보내지 마세요. 저장된 값은 이 앱의 서버에만 있고 화면에 다시 보여주지 않아요. 인스타그램에서 로그아웃하면 쿠키는 무효가 됩니다.

본인이 올렸거나 저작권자의 허락을 받은 콘텐츠만 저장하세요.
